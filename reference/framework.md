# 框架 · 窝轮盈亏比鱼身定位（理念与判据）

> 多空双向。本篇管**"为什么"与判据定义**；严格执行序列见 `workflow.md`（本篇不写"先调什么再做什么"，只定义判据本身）。所有数据来自 Longbridge OpenAPI MCP。
>
> **版本 v5（2026-08-12）** · 变更见 [`../CHANGELOG.md`](../CHANGELOG.md)。本版把判据从单一"资金结构+CLV"扩为**多维证据体系**：改写 L4（CLV 实证降级为弱均值回归、永不作进场扳机）、L3 补抛物线速度量化口径，新增 L9（进场三维证据投票）、L10（抗操纵两维 + 鱼身去神圣化）、L11（对抗式独立盲审）、L12（结论使用纪律）。

> **阈值标记**：★=有实证/机制支撑的硬阈值；☆=经验值，待校准、用户可覆写；⚠=来源存疑需谨慎。凡带 ☆ 的数字都不是定论，是可执行的占位。

## L0 内核
窝轮无独立价值，**盈亏比是合成的**。脱离方向，期望值为负（时间损耗 + 买卖价差是确定性流出）。
真实分解：`ΔW/W ≈ 实际杠杆×ΔS/S + vega×ΔIV − theta×Δt − 价差`。
方法论主路径：**先定方向 → 鱼身定位 → 多维证据印证 → 选券 → 量盈亏比 → 对抗复核 → 执行**（方向驱动，非相对价值套利）。

## L1 盈亏比的真相
- **杠杆等比放大盈亏两端，不改善盈亏比。**
- 真正制造不对称的是三样：① 凸性（gamma，平价/价外最强）；② 标的目标/止损距离比；③ 严守止损。
- 一切盈亏比数字都隐含前提：**到止损价就走，不持有到归零。**
- **⚠ "有效杠杆最高"是选券里最贵的陷阱**：接口给的"有效杠杆"是瞬时理论值，深度价外证价格分母极小，会把它灌成虚高（一张需要标的暴跌才兑现的"彩票杠杆"）。方向对、但标的只小幅顺行时，价外证的高杠杆兑现不了，反被 theta + 价差侵蚀。**别按"杠杆最大"选券**——高杠杆数字必须与价内外程度 + delta 联看（见 L8）。
- **⚠ 止损折算优先用 delta 反推实际杠杆**（实际杠杆 ≈ delta × 标的价 ÷ 权证价 ÷ 换股比），而非直接信接口的 `effective_leverage`——后者对深度价外证失真（见 L8 止损折算）。

## L2 鱼身定位（组织全局的尺，双向对称）

| | 认购健康 | 认沽健康 | 鱼尾（禁） |
|---|---|---|---|
| 位置 | 突破后中段 | 破位后中段 | 抛物线顶 / 瀑布底 |
| 大单 | 净进（吸筹） | 净出（派发） | **结构翻转** |
| 散户 | 净出 | 净进 | **结构翻转** |
| 距历史价位 | 无关 | 无关 | 无关 |

- **鱼头** = 刚拐 · 轻仓 · 限亏工具（价外证）；
- **鱼中** = 确认 · 核心仓 · 高效工具（平价证 / 价内证）；
- **鱼尾** = 一票否决。

**鱼段的可计算边界**（消除"中段"的口语歧义，用 ATR 归一）：
- 鱼头 = 从最近一次通道突破/破位起，行进 ≤ 1×ATR（☆）；
- 鱼中 = 行进 1~3×ATR（☆）且趋势延续未翻转；
- 鱼尾 = 触发 L3 判据。
> ATR 倍数是☆结构化占位值，随标的波动性与周期校准。

> **本框架只做窝轮（认购/认沽），不做牛熊证（CBBC）**：牛熊证有强制收回机制，触及收回价即时归零、不可控，风险性质与窝轮不同，故整体排除。下文所有工具选择只在窝轮的价内/平价/价外之间做。

## L3 鱼尾判据：结构 + 速度，不是幅度
- "跌太多"之于认沽 = "涨太多"之于认购 = **同一个最贵的本能**。下跌趋势天生不断创相对新低，那正是它该干的事。
- **鱼尾 = 资金结构翻转 ∩ 抛物线速度，双证缺一不成立。**
- **绝不许按涨跌幅枪毙。缺速度证据不得判鱼尾。错杀 = 框架有洞，必须补。**

**抛物线速度的量化口径**（三项同时成立才算"抛物线冲刺"）：
1. **累计涨/跌幅位于该股自身历史分位 ≥ 90 分位（★用自我分位，不用绝对幅度**——绝对幅度会错杀强势股）；
2. **最近 1 日收益相对近 20 日的 z-score ≥ 2.0（☆）**（异常加速）；z 的均值/标准差窗口**不含当日那根**（防被判定量污染归一化基准）；
3. **涨幅变化率（ROC 加速度）> 0 且处于自身高分位**（冲刺在加速）。
> 分位 90 / z≥2 是☆经验值。三项缺一 = 速度证据不成立 → 不判鱼尾。

## L4 资金结构与 CLV：主力是参考，不是裁决
- 结构性质：吸筹 = 大进散出；派发 = 大出散进；鱼尾 = 结构翻转。
- **但主力会错、会诱多诱空、大单也可能只是发行商对冲。** 资金的职责是"确认或证伪方向判断"，**不替我下结论**；再强的单日大单也不是保票。资金与价格/位置矛盾时是"警示"，不是"反向信号"。
- **⚠ CLV（收盘位置 =（收−低）/（高−低））是弱均值回归信号，不是顺势脚印。** 实证：以每只票自己的历史分位做尺，高 CLV（收在当日高位）次日倾向**反跌**而非续涨（t+1 信息系数 ≈ −0.03，扣成本不可交易）。**故：**
  - **CLV 永不作进场扳机**——别因"今天收在高位=吸筹"就进场，那是反的；
  - CLV 唯一稳妥角色在**离场端**（持仓中收盘跌破自身低分位 = 结构走弱的软佐证，不单独触发离场）；
  - 进场方向判定用实时资金结构 + 逐笔（见 L9），不用 CLV。

## L5 进出场纪律
- **未确认才等，已确认就动**（价格突破/破位 + L9 证据充分 = 足够进场，不必二次确认）。
- **犹豫放在离场端，不放进场端。** "别追"的定义 = 现价进 · 对的仓位 · 证明后加 · 限价不追最优卖价 · 不在一天大的趋势上 All-in；**不等价格回落到更便宜**。
- **跟主力 = 跟进也跟出**；信心是从资金流租来的 → 结构一翻转立即走。
- **离场信号优先级**：① 结构反向翻转（认购：大单净进→净出 + 散户净出→净进；认沽镜像）= **一级信号，当日减/平**；② 价格止损 = 二级兜底。一级信号触发时，**禁止**以"未达价格止损"为由降级为"观察持有"。与 L8 折算止损**取先到者执行**。

## L6 双向执行不对称
方向对称，执行不对称：**认沽止损更紧、仓位档位下调一级**（下跌反抽与轧空比上涨凶；短覆盖无消息也能机械引爆）。
> 注：是否保留此不对称随做空腿实盘表现校准——若做空腿风险未显著更高，可回调至完全对称。当前保留。

## L7 两道独立闸门
**"股票鱼身定位"与"窝轮经济性"分开判，不可合并。**
- 股票可以是鱼中（被吸筹），但其窝轮可能不经济（IV 极值 / 回本过远 / 杠杆被压）→ 仍不交易。
- 反之窝轮再便宜，股票若是鱼尾 → 也不做。**两闸全过才出手。**

## L8 窝轮经济性判据（第二道闸）
IV（同标的横比、避板块极值）· 实际杠杆 · 溢价/回本点 · 价内外+delta（价内高胜率/价外高凸性）· **到期 ≥3 月（★避 theta 悬崖）** · **街货 <50%（★避发行商控盘）** · 发行商价差 · 换股比。

- **选券三问（同一标的多只候选轮之间怎么挑，别只看杠杆）**：
  1. **价内外多少？** 深度价外（价外程度 ≥ 25%，☆）= 需标的大幅顺行才有价值，方向对但只小动就白扛——除非明确做鱼头限亏、且看大波动，否则别选。价内/平价（|delta| ≥ 0.5，★）跟随正股紧，鱼中优先。
  2. **回本点离现价多远？** 把"回本"和"目标"都换算成**标的顺行幅度**再比：`回本所需幅度 R_be =|回本点−现价|/现价`；`目标幅度 R_tg =|目标位−现价|/现价`。**IF R_tg < R_be → 淘汰**（目标到不了回本，期望为负）；R_be ≤ R_tg < 1.5×R_be（☆）→ 安全边际薄，降级标注；R_tg ≥ 1.5×R_be → 通过。
  3. **溢价吃掉多少？** 溢价 > 20%（☆）意味着大部分是时间价值/水位，横盘与小幅顺行都在漏血 → 淘汰或仅方向极强的短打保留。低溢价的价内证把方向红利留给你。
- **工具配鱼身**：鱼头 → 价外限亏（明确赌大波动、限亏）；鱼中 → 平价证 / 价内证（高 delta、低溢价，把方向高效变现）。
- **工具配周期**：短打 → 价内（低 theta、高 delta）；波段 → 平价/价外（凸性）；偏长 → 扣 theta，价外不宜久放。
- **止损位按杠杆折算，不抄正股技术位**：次序反过来——先定**可承受的窝轮回撤 D_w**（如 −10~12%，☆）→ ÷ 实际杠杆 = 标的容忍幅度 D_s → 叠加进场价得标的止损线（认购 `现价×(1−D_s)`，认沽 `现价×(1+D_s)`）。直接抄正股颈线/平台/整数关会让止损被杠杆放大数倍（例：标的 −8% × 3x ≈ 窝轮 −24%，违背 L1「到止损就走」）。**实际杠杆用 delta 反推（L1），不直接信接口 effLev；价外证折算不可靠时明确标注。**
- **盈亏比门槛**：`RR =|目标窝轮回报| /|止损窝轮回报|`。**RR < 1.5（☆）不做。** 用实际杠杆把标的三情景（base/目标/止损）映射到窝轮回报（线性近似，凸性使顺势侧更优，隐含"到止损即走"）。

## L9 进场证据投票：要正向证据，不是"没反向就进"
亏损的最大来源不是"做了反向"，而是"中性/没有正向证据也放行"——价格突破了，但资金没表态，就凭价格单扛。**把进场从"没有反向信号就进"升级为"必须有足够正向证据才进"。**

三维平权投票（认购看多，认沽取镜像），每维三态记 +1/0/−1：
- **结构维**（数据源 `capital_distribution`）：大单净进+散户净出=吸筹(+1)；大单净出+散户净进=派发(−1)；否则 0。
- **资金流维**（数据源 `capital_flow`）：当日累计净流入>0 且斜率≥0 =流入向(+1)；<0 且斜率≤0 =流出向(−1)；方向与斜率矛盾=0。
- **逐笔主动买维**（数据源 `trades`，剔除竞价特殊单）：主动买占主动成交（分母=主买+主卖，不含中性）≥55%(+1)／≤45%(−1)／中间=0。

裁决（认购；认沽把"正向"理解为看跌方向证据）：
- **≥2 维正向 → 证据充分，可进**；
- ≥2 维反向 → 方向已证伪，不进（持仓则考虑反向）；
- 其余（含全中性）= **证据不足，不进**（补证据或换标的，别硬进）。

> **投票的角色边界**：它只裁决"进不进"（准入门槛/否决权），**不裁决方向本身**——方向仍由价格通道给出（见 workflow 步骤1）；资金投票是准入闸，不是方向来源（与 L4"资金是参考非裁决"一致）。
> 55/45% 是☆经验值，待校准、可覆写。

## L10 抗操纵：价量净额是主力写的剧本，识庄要下沉到最难伪造的层
**鱼身去神圣化**：框架把"标准鱼身"（突破站稳+放量+匀速上行+距高位有空间）当最安全的进场画像——但这**恰是主力诱多形态的教科书定义**。价、量、净流入全是主力成本最低、最能构造给你看的东西；标准鱼身是信息熵最高、最该外部佐证的段，不是最放心的段。控盘票里"缩量新高=顶背离"甚至可能是彻底反指。

**两维最难伪造的抗操纵原料**（只呈现客观事实、不下裁决，是否对倒/诱多由你按框架判）：
- **逐笔主动方向序列**（数据源 `trades`）：大单**连续同向**扫单 vs **买卖交替**对敲，是两种完全不同的性质。
- **CCASS 全席位持仓集中度/增减**（数据源 `broker_holding_detail`，T+1 非实时）：前几大席位集中度、昨日增减持 Top 席位。可与今日逐笔交叉——如"价在拉升但集中席位在减持"= 拉高出货的原料。

> ⚠ 数据档次约束：实时经纪商队列（`brokers`）/ 十档盘口（`depth` 2-10 档）属 LV2 权限；`trades` 逐笔与 `broker_holding_detail` CCASS（交易所披露）**不受行情档次限制**，LV1 也完整可得——所以抗操纵两维锚定在这两个工具上。

## L11 对抗式独立盲审（决策卫生结构）
抗操纵不要塞进主判断里（会污染每次解读），而是做成**独立的第二趟"魔鬼代言人"审查**：
- **盲**：审查者只看候选进场腿的参数 + 原始多维/微观结构数据，**看不到主判断的看多/看空理由**——独立性是核心，否则只是自我背书。
- **按方向分组的主力红旗清单**：看多腿查"突破画像过于标准=诱多教科书、控盘缩量新高、拉高出货"；看空腿查"恐慌尾端诱空、挖坑洗盘、超跌反弹陷阱、空头挤压"。
- **克制**：默认放行，只有多条红旗齐备且证据够硬才判"疑似操纵"——**宁可漏杀，不过度解读**。
- **产出**：独立审查结论（疑似/放行 + 置信度 + 具体 concern），供出手前对照。技术解读走主线，抗操纵走这条独立线，两者解耦。

## L12 结论的使用纪律（怎么对待自己的判据结论）
判据会骗人，比判据更会骗人的是"对判据结论的过度自信"。几条元规则：
- **对抗复核 ≠ 独立证据**：用同一批数据、同一市场环境再算一遍，只是同源复算；真正的独立验证需跨市场环境 / 样本外。
- **不可回测 = 可信度天花板**：大单结构 / 资金流只有当天、无历史、不可回测——能用来 live 判断，但**不能被"回测验证过"**，可信度天上有顶。可回测的（如 CLV）与不可回测的互补，别把不可回测的当铁证。
- **"已定论"都隐含"仅在当前市场环境内"**：震荡市验出的结论，趋势市/高波动环境未必成立，别外推。
- **小样本只论机制、不论收益**：十几笔交易只能说清"机制对不对"，不能用来声称"这套能赚钱"。
- **口径纪律**：任何进结论的数字先问三问——哪个口径、分母是什么、能不能一条命令复现。同一批交易"赚赔比"按金额/按百分比/利润因子能差一倍多，会把你导向完全不同的改进方向。
- **归一化分母不能取自被判定量本身**：否则归一化掉的正是你要判的量级信息。

## L13 数据现实（Longbridge OpenAPI MCP）
- 不直接给窝轮 theta（需用 IV + 到期估算）；`delta`/`effective_leverage`/`premium`/`itmOtm`/`balance_point` **只在 `warrant_list`**，`warrant_quote` 不含（只有 IV/到期/街货/行权价/换股比）。
- **`calc_indexes` 对正股的量能字段（`volume`/`turnover`/`capital_flow`/`volume_ratio`/`amplitude`/`turnover_rate`/多周期涨跌率）均可得**（券商口径截面值）；返 null 的是**权证/期权专属字段**（delta/gamma/theta/vega/rho/IV/premium/itmOtm/strike/balance_point/effLev——正股无这些概念）。⚠ 但 `calc_indexes` 只给**单点截面、不给历史序列**：ATR% / CLV / 量分位 / Donchian / 抛物线速度等**逐日时序派生量必须从 `candlesticks` 自算**。
- **涨跌口径三工具不一致**（换算前必辨）：`calc_indexes.change_rate`="−1.95"（百分数值本身）；`rank_list.chg`、`warrant_list.*` 各字段="−0.0195"（小数分数，需×100）。
- K 线时间戳可能偏移 +1 日（读某日收盘取比该日历日早一天的那根，用 `prev_close` 交叉校验）。
- 窝轮只存在于流动大中盘（仙股异动无关）；**部分标的无轮 → 不可执行即出局。**
- **价格有原生预警 push，结构（`capital_distribution` 大单/散户 + `capital_flow`）无 push、大单仅当天无历史** → 持仓结构监控**只能主动轮询**（如每 30 分钟）；`capital_flow` 斜率是唯一能**先于价格**翻的实时量。
- `capital_distribution` 在盘前/无成交时段可能返空或时间戳异常 → 判为"结构未就绪"，该维记中性，不臆造吸筹/派发。
- **权限档次**：核心链路只依赖 LV1 就能全得的工具（quote / calc_indexes 除权证专属字段 / candlesticks / capital_distribution / capital_flow / trades / broker_holding_detail / warrant_list 含 delta·effLev·premium·IV / warrant_quote / corp_action / static_info）；**仅 `depth` 2-10 档与 `brokers` 实时队列属 LV2**。运行时可用一次 `depth` 探测档次（asks 长度 ≥5 = LV2）。
